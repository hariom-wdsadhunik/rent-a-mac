# CLOUDFLARE WORKERS DEPLOYMENT GUIDE — RENT-A-MAC

This document defines the exact production deployment pipeline for **Rent-a-Mac** on Cloudflare Workers using OpenNext (`@opennextjs/cloudflare`).

---

## 1. Cloudflare Dashboard Settings

When connecting the GitHub repository `hariom-wdsadhunik/rent-a-mac` to Cloudflare Workers, configure the build settings in the Cloudflare Dashboard as follows:

| Cloudflare Dashboard Field | Required Value | Explanation |
|---|---|---|
| **Framework Preset** | `None` / `OpenNext` | Custom OpenNext worker build |
| **Root Directory** | `/` (Project Root) | Repository root |
| **Build Command** | `npm run build` | Runs `prisma generate && next build && opennextjs-cloudflare build --skipNextBuild` |
| **Deploy Command** | `npx wrangler deploy` | Deploys generated `.open-next/worker.js` and `.open-next/assets` |
| **Build Output Directory** | `.open-next` | Artifact directory generated by OpenNext |

---

## 2. Environment Variables (`ENVIRONMENT_VARIABLES`)

Set the following environment variables in **Cloudflare Dashboard ➔ Workers & Pages ➔ Settings ➔ Environment Variables**:

```env
# Node.js Compatibility (Required)
NODE_VERSION="20.17.0"

# Application URL
NEXT_PUBLIC_APP_URL="https://rent-a-mac.your-subdomain.workers.dev"

# Database Connection (PostgreSQL - Neon / Supabase / Vercel Postgres)
DATABASE_URL="postgresql://user:password@ep-cool-project-123456.us-east-2.aws.neon.tech/rent_a_mac?sslmode=require"

# Auth Secrets
JWT_SECRET="your-secure-production-jwt-secret-min-32-chars"
ADMIN_EMAIL="admin@rent-a-mac.com"
ADMIN_INITIAL_PASSWORD="YourSecureAdminPassword123!"

# Stripe Credentials
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY="pk_live_..."
STRIPE_SECRET_KEY="sk_live_..."
STRIPE_WEBHOOK_SECRET="whsec_..."
```

## 3. Worker Configuration (`wrangler.jsonc`)

The repository includes [wrangler.jsonc](file:///d:/Rent-a-Mac/wrangler.jsonc):

```json
{
  "$schema": "node_modules/wrangler/config-schema.json",
  "name": "rent-a-mac",
  "main": ".open-next/worker.js",
  "compatibility_date": "2024-09-23",
  "compatibility_flags": [
    "nodejs_compat"
  ],
  "assets": {
    "directory": ".open-next/assets",
    "binding": "ASSETS"
  }
}
```

## 4. Local Deployment Testing

To test the build & dry-run deployment locally:

```bash
# 1. Clean install dependencies
npm ci

# 2. Run full production build (Next.js + OpenNext Worker)
npm run build

# 3. Dry-run Wrangler deployment
npx wrangler deploy --dry-run
```
